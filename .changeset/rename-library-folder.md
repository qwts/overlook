Rename a library folder in place from the library switcher: the new name appears in Finder or Explorer while the library ID, keys, encrypted database, albums, backup links, and display name stay untouched. Renames run through the journaled relocation engine (crash-safe, refusal-first), validate names conservatively for every platform the disk might visit, and support case-only renames on case-insensitive filesystems.
