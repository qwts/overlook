Library switcher rows now have one ⋯ button beside the library instead of a checkbox and four icon buttons. The ⋯ menu (also opened by right-click, Shift+F10, or the Menu key) lists Edit display name…, Rename folder…, Move…, and Remove library from list…. An action a library can't take stays in the menu, disabled with the reason. To move several libraries at once, choose Move several… below the list and check the ones to move; checked rows are highlighted. After any of these, focus returns to where you started. Dialogs now keep a 16px margin from the window edge at any zoom.
