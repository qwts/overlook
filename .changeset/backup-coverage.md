Keep on this device only (photo context menu): a photo can be taken out of automatic backup, and when the provider already holds a verified copy that copy is removed — after the local original is proven, the decision is recorded, and a manifest generation that already says so has landed, so recovery never promises what the backup no longer holds. Removing a provider copy is an irreversible-tier confirmation that names the provider and account; a photo with no cloud copy simply stops being backed up. A shared encrypted original stays with the provider while another photo still references it; a failed removal is retried by later backups and shown as pending. Back up again returns the photo to the ordinary verified upload. Backup manifests move to schema 14 and record what they deliberately do not hold; restore recreates those photos as honest placeholders.
