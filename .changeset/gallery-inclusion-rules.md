The sidebar gains derived **RAW** and **Unavailable** sources with exact counts, and Settings → General → All Photos adds inclusion rules: show or hide unavailable items and a minimum size with an explicit "None — show every size" default. Rules change only what All Photos shows, unknown dimensions are never treated as zero megapixels, the status bar discloses how many photos a rule hides, and the rules are library data carried by backup and restore (manifest schema 7, database schema 27).
